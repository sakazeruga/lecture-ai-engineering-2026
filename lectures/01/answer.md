# 第1回 解答

## 演習

- 講座に固有の質問（宿題の3レベル）へのモデルの回答（要約でよい）：
  2モデルで各3回、計6回質問した。どの回答も講座の定義を知らないまま、AI講座でよくある分類として「基礎・応用・発展」のような3段階を説明した。「分からない」とだけ答えた回はなかった。多くは「一般的に」「可能性が高い」と断りを入れ、6回とも講座の資料などで確認するよう勧めていた。プロンプト設計の深さや、ビジネスへの適用度合いの3段階といった、別の解釈を並べる回もあった。
- 用語集の正しい意味と比べて気づいたこと：
  `data/glossary.json` の `homework-levels` では「基礎（講義内容の確認）」「実装（自分でコードを書く）」「発展（調査や試行）」の3段階で、どれか1つに取り組めばその回の宿題は完了となり、原則として採点はしない。モデルの答えは「基礎」「発展」という語は重なったものの、2段階目はすべて「応用」や「標準」で、「実装」は出なかった。「どれか1つで完了」と「原則採点しない」は6回とも出なかった。`gemini-3.8-flash` は3回ともレベル1を「必須」と説明し、レベルを順に積み上げる前提で答えていたが、これは実際のルールと異なる。もっともらしいが正しくない答えの例だと思う。
- 表示できたトークン数（入力 / 出力）：
  例：`gemini-3.5-flash-lite` に「LoRAとは何ですか？」と質問して 入力 7 / 出力 590。全12回で表示できた（下の表）。

## 宿題

- 取り組んだレベル：基礎
- やったこと：
  同じ質問を3回ずつ、`AIE_MODEL` でモデルを変えて実行し、回答の違いを比べた。temperature は変えず、既定のままにした。
  - モデル：`gemini-3.5-flash-lite`、`gemini-3.8-flash`
  - 質問：一般的な用語の「LoRAとは何ですか？」と、講座に固有の「AIE2026の講座の宿題にある「3レベル」とは何ですか？」
  - 実行方法：`lectures/01/run_basic.py` で計12回実行し、出力を `lectures/01/results.json` に保存した。無料枠の毎分上限に収まるよう、実行の間隔を `gemini-3.5-flash-lite` は5秒、`gemini-3.8-flash` は15秒空けた
  - 環境：Codespaces ではなくローカルPC（Windows）で実行した
  - AIツール：Claude Code を使い、`app/ask.py` の修正、実行スクリプトの作成、回答の比較、この文章の下書きを行った。回答の要約は `results.json` の出力と照らし合わせた
- 結果：
  12回すべて成功した。429 や 503 は出ず、再試行もなかった。

  出力トークン数（入力トークン数は同じ質問なら毎回同じで、LoRA は 7、3レベルは 21）：

  |---|---|---:|---:|---:|---:|

  | LoRA | gemini-3.8-flash | 699 | 765 | 785 | 749.7 |

- 気づき・疑問：
  - 同じモデル、同じ質問でも、出力の長さと構成は毎回変わった。「3レベル」への `gemini-3.8-flash` の出力は 546〜803 トークンと、特に幅が大きかった。1回だけ試して「こう答える」とは言えないと分かった。
  - LoRA の説明の大筋は全回で一致したが、細かい数字は揺れた。学習パラメータの削減幅も「数％〜1％未満」「1/1000程度」「1万分の1〜数千分の1」と回やモデルで違った。大筋が合っていても、数字はそのまま信じられない。
  - `gemini-3.8-flash` の方が全体に長く、詳しい傾向があったが、講座に固有の質問では正解に近づかなかった。性能の高いモデルでも、知らないことは答えられない。むしろレベル1を「必須」と具体的に説明した分、誤りが目立った。
  - 3回ずつの比較なので、モデルの差について言えるのは傾向までである。
  - 疑問：回答が確認を勧めていても、中身は推測である。どの部分が根拠のある内容で、どの部分が推測なのかを、回答だけから見分ける方法はあるのか。
