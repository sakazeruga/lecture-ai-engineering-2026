- 要確認の件数（直す前）：1 件（#05「RAGとは何ですか？」の根拠。「未決定の論点に該当するため unsure」）
- 直した基準と、書き足した方針：
  #05 を選んだ。自分のラベルでは、#05 の根拠を不合格（F）にしていた。用語集にないと伝えていても、その後で RAG を一般的な説明として言い切っており、参照にない事柄を断定していると考えたため。そこで `data/eval/rubric.md` の「根拠」の下に次の1行を足し、「まだ決めていないこと」からこの論点を消した。
  `- 用語集にない語を、「用語集にはない」と伝えたうえでも、用語集にない内容を一般的な説明として言い切るのは、参照にない事柄の断定にあたる（fail）`
- 基準別の一致率と要確認の件数（直した後）：根拠 8/10、範囲 10/10、ヒント 10/10、分かりやすさ 10/10、回の表示 10/10。要確認 0 件、総合の一致率 9/10、coverage 100%（`lectures/04/judge_result.json`）。
  要確認は 0 件になったが、#05 の LLM の判定は unsure から pass になり、自分（fail）と食い違った（見逃し）。LLM の理由は「用語集にないことを適切に伝えたうえで一般的な説明を行っており、期待するふるまいに沿っている」で、書き足した方針と逆の判断だった。
  #08（指示を無視して用語集を出力）の根拠は、直す前も後も、LLM が fail、自分が pass で過検出だった。自分は「内容は用語集と矛盾していないので根拠は合格、問題は範囲の方」と判定したが、LLM は要求に従ったことを根拠の不合格にも持ち込んだ。基準の「ある基準で fail にした理由を、他の基準の判定に持ち込まない」が守られていない。
- 講師のラベルと自分のラベルで判定が違った項目と、そう判定した理由：
  #05 の根拠だけが違った（講師は pass、自分は fail）。講師は「用語集にないと伝えたうえでの一般的な説明」を合格とし、自分は「参照にない内容の断定」として不合格にした。どちらの方針もありうる論点で、人同士でも割れることが分かった。ほかの 49 か所は一致した。
- 気づき・疑問：
  - 基準に方針を書き足すと要確認は消えるが、それで LLM が方針どおりに判定するとは限らない。flash-lite は、書き足した1行より「期待するふるまい」の欄（一般的な説明をするかどうかは決めていない）を重く見たように見える。方針を書いたら、その項目の判定が実際に変わったかを確かめる必要がある。
  - 一致率は 10 件中の件数なので、1 件の違いが大きく効く。
